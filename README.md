# Krunal Prajapati Resume Portfolio

A simple, resume-style single-page website inspired by a traditional two-column CV layout, with restrained teal/gold accents and tool icons.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository for this website.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. Copy the URL shown in the Pages settings.

## Before publishing
- Confirm contact details and dates.
- Replace or add your actual LinkedIn URL if you want it shown.
- Review every skill and experience bullet to ensure it accurately represents your work.
